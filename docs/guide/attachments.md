# Attached files

You can attach files of any type to a task: a contract, a spreadsheet, a PDF. The file stays where it is on your computer, and EasyTask keeps its path.

## Attach files

- Open the menu of the task and choose **Attach files…**, then pick one or more files.
- Or use the files field in the [details panel](./groups-sections-tasks#the-details-panel).

A task with files shows a paperclip with the number of files. Click it to see the list.

## The list of files

| Action | How |
| --- | --- |
| Open a file | Click its name. It opens with the default app of the system |
| Add more files | **Add files** at the bottom of the list |
| Remove a file | The **X** next to it. The file on your computer is not touched |
| Find a missing file | See below |

## Missing files

If a file is no longer at its saved path, its name is crossed out and a warning icon appears. Click the name, or the folder button, and pick the file in its new place (**Update path**).

## Programs and scripts

For safety, EasyTask does not open programs and scripts (for example `.exe`, `.bat`, `.msi`, `.ps1`, `.js`, `.sh`, `.app`). You can still attach them, but a click shows a message and you open them from their folder. They are also not extracted from an exported archive.

## Copies, templates and export

The attached files follow the task when you duplicate or copy it, move it to another note, send it to the trash or archive it and restore it, and when you undo. They are part of [templates](./templates) too. When you export a workspace, a note or a folder, the files are included in the `.easytask.zip` if you choose to include them, like [audio files, images and videos](./audio); in the `.easytask.json` only their paths are saved.

Files cannot be dropped from the file manager onto a task yet: use **Attach files…**.
