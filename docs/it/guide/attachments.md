# File allegati

Puoi allegare a un task file di qualsiasi tipo: un contratto, un foglio di calcolo, un PDF. Il file resta dov'è sul tuo computer, ed EasyTask ne salva il percorso.

## Allegare file

- Apri il menu del task e scegli **Allega file…**, poi scegli uno o più file.
- Oppure usa il campo dei file nel [pannello dei dettagli](./groups-sections-tasks#il-pannello-dei-dettagli).

Un task con dei file mostra una graffetta con il numero di file. Cliccala per vedere l'elenco.

## L'elenco dei file

| Azione | Come |
| --- | --- |
| Aprire un file | Clicca il suo nome. Si apre con l'app predefinita del sistema |
| Aggiungere altri file | **Aggiungi file** in fondo all'elenco |
| Rimuovere un file | La **X** accanto al nome. Il file sul tuo computer non viene toccato |
| Ritrovare un file mancante | Vedi sotto |

## File mancanti

Se un file non è più al percorso salvato, il suo nome è barrato e compare un'icona di avviso. Clicca il nome, o il pulsante della cartella, e scegli il file nella sua nuova posizione (**Aggiorna percorso**).

## Programmi e script

Per sicurezza, EasyTask non apre programmi e script (per esempio `.exe`, `.bat`, `.msi`, `.ps1`, `.js`, `.sh`, `.app`). Puoi comunque allegarli, ma un clic mostra un messaggio e li apri dalla loro cartella. Inoltre non vengono estratti da un archivio esportato.

## Copie, template ed esportazione

I file allegati seguono il task quando lo duplichi o lo copi, lo sposti in un'altra nota, lo mandi nel cestino o lo archivi e lo ripristini, e quando annulli. Fanno parte anche dei [template](./templates). Quando esporti un workspace, una nota o una cartella, i file sono inclusi nel `.easytask.zip` se scegli di includerli, come i [file audio, le immagini e i video](./audio); nel `.easytask.json` vengono salvati solo i percorsi.

I file non si possono ancora trascinare dal gestore file su un task: usa **Allega file…**.
